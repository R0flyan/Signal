# Ориентир дизайна

Источник пользователя: локальный `ppProject.fig` и [Figma ppProject](https://www.figma.com/design/U4FTq8B0Xhgd2eQvsRxfiA/ppProject?node-id=1-46).

Figma-коннектор вернул сетевую ошибку. Локальная копия прочитана как ZIP с Kiwi-схемой и документом: 1 432 слоя, 5 верхнеуровневых фреймов. Локальный файл и ссылка не изменялись. Исходный фрейм `1:46` — обложка; рабочие фреймы — подключение площадок, темы жалоб, карточка темы, оповещения и отчёт.

Сохранены: бренд «Сигнал», фиктивный бренд «Хюгге Хоум», навигация, названия тем, общий сценарий и светлая палитра.

Добавлены адаптивность, рабочие фильтры, поиск, экспорт и локальные сценарии задач. Экран обзора и вспомогательные разделы развивают концепт; это не обещание совпадения каждого пикселя.

Числа и содержание макета трактуются как вымышленные продуктовые примеры, а не подтверждение возможностей API или инструкции к действиям. Партии и ИИ-выводы — демонстрационная разметка. Файлы промежуточного декодирования исключены из Git; оригинальный `.fig` не включён в проект.
