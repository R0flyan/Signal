# Сигнал

Фронтенд-прототип сервиса агрегации и аналитики отзывов с маркетплейсов. Основан на ориентировочном макете: светлый интерфейс, фиолетовые акценты, темы жалоб и проверяемые выводы.

## Запуск

Нужен **Node.js 24 или новее**. Внешних зависимостей нет, `npm install` не требуется.

```powershell
cd C:\Users\roflyan\Signal
npm run dev
```

Открыть **http://127.0.0.1:5173**. Для остановки — `Ctrl+C` в терминале. Если порт уже занят этим приложением, достаточно открыть страницу. Другой порт:

```powershell
$env:PORT = '5174'
npm run dev
```

После изменения исходников обновите браузер: автоматическое обновление пока не реализовано. Локальный HTTP-сервер обслуживает только статические файлы и удаляет TypeScript-аннотации для браузера. Бэкенда приложения в проекте нет.

## Что работает

- Обзор, темы жалоб, карточка темы, отзывы, товары, оповещения, отчёты, площадки и настройки.
- Фильтры периода, площадки и товара; категории, поиск и сортировка тем; поиск и пагинация отзывов.
- Расчёт сводных показателей и динамики из общего массива из 1 284 отзывов.
- Проверка источников темы и исключение ошибочных совпадений с пересчётом аналитики.
- Локальные задачи, комментарии, статус, ответственный и срок.
- CSV-выгрузка выбранных данных, защита пользовательского текста от CSV-формул.
- Печатная версия отчёта: «Сохранить PDF» открывает системную печать, где можно выбрать PDF.
- Демоформы подключений, настройки оповещений и отметки прочитанного.
- Адаптивный интерфейс, мобильное меню, управление клавиатурой.

Все отзывы, товары, рейтинги и выводы **вымышлены**. Дата среза — **26 октября 2026**, как в дизайн-концепте; новые локальные комментарии используют текущую дату. Шесть демонстрационных вариантов товара представляют ассортимент бренда; 84 карточки в макете — справочное число, а не загруженный каталог прототипа.

Настоящие API-токены не принимаются. Формы используют встроенные `demo-*` значения. Нет авторизации, запросов к маркетплейсам, ИИ-обработки, отправки сообщений и фоновых задач. Изменения сохраняются в `localStorage` текущего браузера. Для восстановления — «Настройки → Сбросить изменения демо». Отключение демоплощадки сохраняет исторические отзывы.

## Проверка и сборка

```powershell
npm test
npm run build
npm run preview
```

Сборка выпускает автономные HTML/CSS/JS в `dist/`, которые можно разместить на любом статическом хостинге. Открывать `index.html` двойным кликом не нужно: ES-модулям требуется HTTP-сервер. TypeScript в этой минимальной сборке освобождается от аннотаций встроенной функцией Node; **это не проверка типов**. `tsconfig.json` предназначен для редактора и будущего подключения `tsc` в CI.

## Структура

```text
src/
  domain/       типы, расчёты, CSV и тесты бизнес-логики
  data/         контракт источника данных и моковый адаптер
  mocks/        согласованный демонстрационный набор
  state/        состояние интерфейса и локальное сохранение
  components/   UI-примитивы, иконки и графики
  pages/        экраны приложения
  main.ts       оболочка, навигация и обработчики действий
  styles.css    дизайн-токены, адаптивные и печатные стили
scripts/        автономная сборка и локальный статический сервер
docs/           архитектура и этапы развития MVP
```

Архитектура следующего этапа: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Дизайн-источник и принятые изменения: [design-reference/README.md](design-reference/README.md).
